# ICU Vent Sim

人工呼吸器管理と VV ECMO 管理を、病態の経過とともに学ぶ教育用 Web シミュレータです（開発中）。

- 公開ページ：https://ito-lab-junshin.github.io/icu-vent-sim/
- 設計書：[DESIGN.md](DESIGN.md)
- 出典管理：[docs/REFERENCES.md](docs/REFERENCES.md)

## ローカルでの起動

```
npm install
npm run dev
```

## 注意

教育用シミュレータです。実在する機器のメーカーとは関係がありません。表示される値は臨床判断に用いないでください。
