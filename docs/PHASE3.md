# Phase 3 指示書：ガス交換・循環・ベッドサイドモニタ・時間制御（Claude Code 用）

作成：2026-11-11　対象リポジトリ：icu-vent-sim　前提：DESIGN.md v0.7、CLAUDE.md、Phase 2 完了（main）

この Phase では、人工呼吸器の設定が「患者の酸素化と換気」に効くようにする。
設定を変えると、SpO2 と PaCO2（EtCO2）が時間とともに変わり、それをベッドサイドモニタとトレンドで見られるところまでを作る。
時間を早送りする仕組みと、「30 分進める」などの時間経過ボタンも作る。

肺は Phase 1 の 1 区画のままとする。シャント率と死腔は、この Phase では確認用のスライダーで与える。
PEEP で肺が開く、肺損傷が進む、といった「肺そのものの変化」は Phase 4 で作る。

## 3. モデル

### 3.1 全体の流れ

```
人工呼吸器の設定 → 呼吸メカニクス（Phase 1、5 ms 刻み） → 1 呼吸ごとの実測値
                                                              ↓
   患者のパラメータ（シャント率、死腔、Hb、酸素消費量、二酸化炭素産生量、心拍出量の基準値）
                                                              ↓
                 定常状態の目標値（gasExchange.js）：その換気が続いたら落ち着く PAO2、PaCO2
                                                              ↓
                 遅い状態（gasDynamics.js）：いまの PAO2、PaCO2 が、目標値へ時間をかけて近づく
                                                              ↓
                 PaO2、SaO2、pH、EtCO2、循環（circulation.js） → モニタ、トレンド
```

遅い状態は、1 呼吸が終わるたびに、その呼吸の長さだけ進める。5 ms ごとには計算しない。

### 3.2 換気（CO2）

```
肺胞換気量 VA =（VTe − 解剖学的死腔 − 肺胞死腔）× 呼吸回数
肺胞死腔 =（VTe − 解剖学的死腔）× 肺胞死腔率
PaCO2 の目標値 = 0.863 × 二酸化炭素産生量 ÷ VA
EtCO2 = PaCO2 ×（1 − 肺胞死腔率）
```

- VA が 0 以下になる設定（VT が死腔より小さい）では、PaCO2 は上がり続ける。上限を設けて計算が壊れないようにする（`// model:`）。
- 時間変化：体内の CO2 の貯蔵を 1 つの区画で表す。換気を変えたあと、PaCO2 は数分〜十数分かけて新しい値に近づく。貯蔵の大きさ（時定数）は `// model:` とし、報告に含める。

### 3.3 酸素化（O2）

```
肺胞気式      PAO2 = FiO2 ×（大気圧 − 水蒸気圧）− PaCO2 ÷ 呼吸商
酸素含量      C = 1.34 × Hb × 酸素飽和度 + 0.003 × PO2
Fick の関係   混合静脈血の酸素含量 CvO2 = CaO2 − 酸素消費量 ÷（心拍出量 × 10）
シャントの式  CaO2 =（1 − シャント率）× Cc'O2 + シャント率 × CvO2
酸素解離曲線  Severinghaus の式：SO2 = 1 ÷（1 + 23400 ÷（PO2³ + 150 × PO2））
```

- 肺毛細血管終末の PO2 は PAO2 と等しいとする（拡散障害は入れない）。
- CaO2 と CvO2 は互いに依存するので、くり返し計算で求める。CaO2 から PaO2 に戻すには、酸素解離曲線を逆に解く（二分法など）。
- 酸素解離曲線は標準の曲線 1 本とし、pH・体温・PaCO2 による移動は入れない（8 の K）。
- SpO2 は SaO2 と同じ値を表示する（測定の誤差や遅れは入れない）。
- 時間変化：FiO2 や換気を変えたあと、PAO2 は数十秒かけて新しい値に近づく（肺の中のガスが入れ替わる時間）。時定数は `// model:` とする。

### 3.4 酸塩基

```
pH = 6.1 + log10（HCO3 ÷（0.03 × PaCO2））
```

HCO3 は患者のパラメータとして与える。腎臓による代償（HCO3 の遅い変化）は、この Phase では入れない（8 の E）。

### 3.5 循環（簡略モデル）

- 平均気道内圧と auto-PEEP が上がると、心拍出量が下がる。心拍出量が下がると、血圧が下がる（血圧 = 心拍出量 × 血管抵抗 + CVP の形）。
- SaO2 が下がる、PaCO2 が上がると、心拍数が上がる。
- 心拍出量の変化は、3.3 の Fick の関係を通して酸素化にも効く。
- 係数はすべて `// model:` とし、関数の形と値を報告に含める（8 の C）。

### 3.6 ベッドサイドモニタ

| 波形 | 数値 | 波形の作り方 |
|---|---|---|
| ECG | 心拍数 | 決まった形を心拍数に合わせてくり返す（不整脈は作らない） |
| 動脈圧 | 収縮期／拡張期（平均） | 決まった形を血圧に合わせて伸び縮みさせる |
| SpO2（脈波） | SpO2 | 動脈圧と同じ周期の脈波 |
| カプノグラム | EtCO2、呼吸回数 | 呼気で立ち上がり EtCO2 で平らになり、吸気で 0 に戻る。呼吸メカニクスの相（吸気・呼気）に合わせる |
| CVP | 平均 | 呼吸に合わせてゆっくり動く |

- 波形の形は教育用の模式図であり、`// model:` とする。
- 人工呼吸器の画面と同じエンジンの状態を表示する（設定を変えると両方が連動して変わる）。
- アラームの上限・下限は学習者が変えられるようにし、範囲を外れた数値は色を変える。初期値と色は 8 の F で決める。
- 特定の機種の画面には似せない（8 の G）。

### 3.7 時間制御

| モード | 動き |
|---|---|
| 実時間 | Phase 2 と同じ。波形を 1 呼吸ずつ描く |
| ×10、×60 | エンジンを 1 フレームに何ステップも進める。波形は間引いて描く。計算は実時間と同じ（結果が変わらない） |
| 時間経過ボタン（30 分、1 時間、4 時間、12 時間） | いまの設定で呼吸メカニクスを少しの間だけ計算して「1 分あたりの換気」を求め、遅い状態だけを大きな刻みで進める。5 ms 刻みを 12 時間ぶん回すことはしない |
| 一時停止 | すべて止まる。設定の変更はできる |

- 時間経過ボタンで進めた間の経過も、トレンドグラフに残す。
- 時間経過ボタンの間は、設定と患者のパラメータが変わらないものとして計算する。予約されたホールドは取り消す。
- 経過時間（シミュレーション開始からの時間）を表示する。

### 3.8 トレンドグラフ

- 1 分ごとの値を記録する：SpO2、EtCO2、心拍数、平均血圧、Ppeak、VE TOT。確認用ページでは PaO2、PaCO2、pH も描く。
- 表示する時間の幅を選べるようにする（30 分、4 時間、全体）。
- 設定を確定した時刻に印を付ける。

### 3.9 画面の配置

DESIGN.md 3 の図のとおり、上に時間制御、左にベッドサイドモニタ、右に人工呼吸器を置く。

- 幅 1280 px で、時間制御・モニタ・人工呼吸器がスクロールなしで見えるようにする。入りきらない場合は、実装を止めずに配置の案を 2 つ作り、報告で示す。
- 学習者の画面には、PaO2・PaCO2・pH を出さない（血液ガスのオーダーは Phase 4）。確認用ページにだけ出す。

### 3.10 確認用の患者パラメータ

シナリオは Phase 4 で作るので、この Phase では確認用のパネルに次を足す。
初期値は 8 の B で決める。機種の既定値でもシナリオの値でもないことを画面に表示する。

シャント率、肺胞死腔率、解剖学的死腔、Hb、酸素消費量、二酸化炭素産生量、心拍出量の基準値、HCO3。

## 4. テスト（受け入れ条件）

理論値と照合できる条件でテストする。許容誤差は ±2 %。

| No. | 条件 | 期待値（理論） |
|---|---|---|
| 1 | 肺胞気式：FiO2 0.21、PaCO2 40、大気圧 760、水蒸気圧 47、呼吸商 0.8 | PAO2 = 0.21 × 713 − 40 ÷ 0.8 = 99.7 mmHg |
| 2 | 酸素解離曲線：PO2 100、60、40、27 mmHg | SO2 = 97.7、90.6、75.0、50.4 % |
| 3 | 酸素解離曲線を逆に解く | SO2 → PO2 → SO2 で元の値に戻る（5 点） |

| 6 | 5 と同じで肺胞死腔率 0.2 | VA = 0.35 × 0.8 × 12 = 3.36 L/min、PaCO2 = 51.4 mmHg、EtCO2 = 51.4 × 0.8 = 41.1 mmHg |
| 7 | pH：HCO3 24、PaCO2 40 | 6.1 + log10（24 ÷ 1.2）= 7.40 |
| 8 | シャント率 0 | PaO2 = PAO2 |
| 9 | シャント率 0.3、FiO2 1.0 | 計算結果の CaO2、CvO2、Cc'O2 をシャントの式に入れ直すと、シャント率 0.3 に戻る。Fick の関係も成り立つ |

## 5. ブラウザでの確認

テストのほかに、実際のブラウザで次を確かめ、報告に結果を書く。

1. 初期状態で、モニタの 5 つの波形と数値が動く。人工呼吸器の波形も動く。
2. 呼吸回数を下げて確定すると、数分かけて EtCO2 が上がる（×10 で確かめる）。
3. O2 を下げて確定すると、数十秒かけて SpO2 が下がる。上げると戻る。
4. 確認用のパネルでシャント率を上げると SpO2 が下がり、O2 を 100 % にしても戻りきらない。
5. PEEP を大きく上げると、血圧が下がる。
6. 「30 分進める」を押すと、経過時間が 30 分進み、トレンドグラフに 30 分ぶんの線が足される。
7. ×60 でも画面が固まらない（1 秒あたりの描画が極端に落ちない）。
8. 一時停止中に設定を変えて確定し、再開すると反映される。
9. 幅 1280 px でスクロールなしに全体が見える。幅 390 px で横にはみ出さない。
10. ブラウザのコンソールにエラーが出ない。
